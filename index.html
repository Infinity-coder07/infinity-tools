How to Get an
OpenRouter API Key ?

Follow these simple steps to generate your OpenRouter API key and use it inside Infinity Tools.

1

Go to the OpenRouter website:
https://openrouter.ai

2

Click Sign Up or Login using your Google or GitHub account.

3

After logging in, open your Dashboard.

4

Navigate to the API Keys section.

5

Click Create Key and copy the generated API key.

6

Paste the API key inside Infinity Tools when prompted.

Help Center

What does Infinity Tools do?

Infinity Tools converts your text prompt into a working web app using HTML, CSS, and JavaScript.

How do I create an app?

  • Enter a clear prompt describing your app.
  • Give your app a name.
  • Add a short description.
  • Click the Generate button.
  • Your app will be created instantly.

What kind of prompts work best?

Be specific. For example:

"A dark themed to-do app with add/delete tasks and local storage"

Why do I need to give an app name?

The app name is used to identify, save, and organize your generated apps.

What should I write in the description?

Write a short summary of your app. Example:
"A simple calculator with a clean UI"

Can I edit the generated app?

No! The generated code is not editable. You can generate a new app with an updated prompt if you want changes.

How do I save my app?

Use the save option after generation. Your app name and description will help you find it later.

Why is my app not generating properly?

This may happen if:
  • Your prompt is too short or unclear
  • The API key has expired
  • The request limit is reached

Is there a limit on prompt length?

Yes, the maximum character limit is 25,000.

Can I generate multiple apps?

Yes, you can create as many apps as you want depending on your API limits.
