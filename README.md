## ✨ Features

* 🧠 **Prompt → App Generator**
  Describe your idea and get a working app instantly

* 📱 **Clean & Minimal UI**
  Smooth experience focused on productivity

* 💾 **Save Your Projects**
  Store apps with name and description

* ⚡ **Fast Generation**
  Get results within seconds

* 🔒 **Offline Friendly**
  Works without APIs for basic apps

* 📂 **Structured Creation**
  Includes app name + description system

---

## 🧩 How It Works

1. ✍️ Enter your app idea (prompt)
2. 🏷️ Give your app a name
3. 📝 Add a short description
4. ⚡ Click **Generate**
5. 🎉 Your web app is ready

---
